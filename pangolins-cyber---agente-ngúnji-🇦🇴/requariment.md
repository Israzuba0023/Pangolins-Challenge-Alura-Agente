# Consultar o Guia Completo

O guia de requisitos, execução local no VS Code e deploy em produção foi documentado em detalhe no ficheiro:

👉 **[REQUIREMENTS.md](./REQUIREMENTS.md)**

Para rodar localmente no VS Code:
1. `npm install`
2. Criar ficheiro `.env` com `GEMINI_API_KEY=sua_chave`
3. `npm run dev`
4. Aceder a `http://localhost:3000`
